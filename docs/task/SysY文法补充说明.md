# SysY 文法补充说明

1. 数组定义的维度和函数形参数组维度都必须为常量。数组形参文法有一处错误，应修正为：

   ```ebnf
   FuncFParam -> BType Ident [ '[' ']' { '[' ConstExp ']' } ]
   ```

2. `-2147483648` 应解释为 `-(long long)2147483648`，词法分析阶段需要注意这一点。

3. SysY 文法说明中写道：“`Exp` 在 SysY 中代表 `int/float` 型表达式，故定义为 `AddExp`；`Cond` 代表条件表达式，故定义为 `LOrExp`。前者的单目运算符中不出现 `!`，后者可以出现。”但实验要求允许 `Exp` 为 `int`、`float` 或 `bool` 型表达式，单目运算符 `!` 可以出现在任何位置，不限于 `Cond`。例如，`int a = 5; return a + !a;` 是合法语句，需要考虑三种类型之间的隐式类型转换。

4. C 语言中的浮点常量属于 `double` 类型，SysY 中的浮点常量属于 `float` 类型。词法分析阶段将单个浮点常量字符串转换为 `float` 时，尤其处理十六进制浮点常量时，推荐先用 `double` 计算结果，再转换成 `float`，以减少浮点误差。

5. C 语言中的 `++` 是自增运算符。SysY 中的 `++a` 表示 `+(+a)`，也就是连续使用两个单目 `+` 运算符，因此结果与 `a` 相同。

6. C 语言中的全局声明 `const int a = 5; int b[a];` 不合法，即使 `a` 是常量，也不能作为数组维度。SysY 允许这种写法：只要 `a` 能在编译期求值，就可以作为数组维度。

7. SysY 运行时库中的 `putf` 函数不要求实现。

8. 其他未说明的部分均可参考 C 语言标准完成实验。
