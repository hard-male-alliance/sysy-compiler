# SysY 运行时库（2022 版）

SysY 运行时库提供输入输出和计时等功能。这些库函数无需在 SysY 程序中声明，可以直接在函数内调用。部分函数参数类型超出 SysY 本身支持的数据类型，例如格式字符串；SysY 编译器仍需正确传递这些参数。

> 与 2020 版相比，SysY 2022 增加了 `float` 基本类型，并支持元素类型为 `float` 的多维数组。

## 1 运行时库文件

- `libsysy.a` 和 `libsysy.so`：面向目标平台的静态库和动态库。正式评测统一使用静态链接。
- `sylib.h`：运行时库函数声明。

SysY 源程序不包含 `sylib.h`；编译器负责识别并处理对这些函数的调用。本仓库提供的运行时文件见 [`../lib/`](../lib/)。

## 2 输入输出函数

### 2.1 `int getint()`

输入一个整数并返回其值。

```c
int n;
n = getint();
```

### 2.2 `int getch()`

输入一个字符，返回该字符的 ASCII 码。

```c
int n;
n = getch();
```

### 2.3 `float getfloat()`

输入一个浮点数并返回其值。

```c
float n;
n = getfloat();
```

### 2.4 `int getarray(int[])`

输入一个整数序列。第一个整数表示随后输入的整数数量，该数量作为返回值；后续整数写入传入的数组。函数只取得数组起始地址，不检查数组容量。

```c
int a[10][10];
int n;
n = getarray(a[0]);
```

### 2.5 `int getfarray(float[])`

输入一个整数和若干浮点数。第一个整数表示随后输入的浮点数数量，该数量作为返回值；后续浮点数写入传入的数组。函数只取得数组起始地址，不检查数组容量。

```c
float a[10][10];
int n;
n = getfarray(a[0]);
```

### 2.6 `void putint(int)`

输出一个整数。

```c
int n = 10;
putint(n);
putint(10);
putint(n);
// 输出：101010
```

### 2.7 `void putch(int)`

将整数参数作为 ASCII 码输出对应字符。参数范围应为 0 至 255，函数不检查合法性。

```c
int n = 10;
putch(n); // 输出换行符
```

### 2.8 `void putfloat(float)`

输出一个浮点数。

```c
float n = 10.0;
putfloat(n);
putfloat(10.0);
putfloat(n);
// 输出：10.00000010.0000010.000000
```

### 2.9 `void putarray(int, int[])`

第一个参数为要输出的整数数量 `N`，第二个参数为数组。输出时在整数之间插入空格。函数不检查参数合法性。

```c
int n = 2;
int a[] = {2, 3};
putarray(n, a);
// 输出：2:2 3
```

### 2.10 `void putfarray(int, float[])`

第一个参数为要输出的浮点数数量 `N`，第二个参数为数组。输出时在浮点数之间插入空格。函数不检查参数合法性。

```c
int n = 2;
float a[] = {2.0, 3.0};
putfarray(n, a);
// 输出：2:2.000000 3.000000
```

### 2.11 `void putf(<格式串>, int, ...)`

第一个参数为格式字符串，只支持 `%d`、`%c`、`%f` 三种格式符。普通字符原样输出；格式符依次取得后续参数，并按整数、字符或浮点数格式输出。

```c
int n = 2;
int a[] = {2, 3};
putf("%d: %d(%c), %d(%c)", n, a[0], a[0] + 48, a[1], a[1] + 48);
// 输出：2:2(2), 3(3)
```

## 3 计时函数

`starttime` 与 `stoptime` 用于测量一段 SysY 代码的运行时间。程序可以插入多对调用，并在结束时获得每对调用的耗时及累计耗时。计时调用不可嵌套。

### 3.1 `void starttime()`

启动计时器，必须与 `stoptime()` 配对。

### 3.2 `void stoptime()`

停止计时器。程序结束时，运行时库输出每个计时器的时间及累计值，格式为：

```text
Timer#编号@开启行号-停止行号: 时-分-秒-微秒
```

示例：

```c
void foo(int n)
{
    starttime();
    for (int i = 0; i < n; i++)
        system("sleep 1");
    stoptime();
}

int main()
{
    starttime();
    for (int i = 0; i < 3; i++)
        system("sleep 1");
    stoptime();
    foo(2);
}
```

示例输出：

```text
Timer#001@0010-0012: 0H-0M-3S-3860us
Timer#002@0005-0007: 0H-0M-2S-2660us
TOTAL: 0H-0M-5S-6520us
```
