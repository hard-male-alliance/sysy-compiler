## 二 编译器功能要求及评分

### 上机作业模块划分及分数

平时作业包括书面作业（15 分）和上机作业（35 分）。课程最终成绩中，平时作业成绩和期末考试成绩各占 50%，因此这里的 1 分就是最终成绩中的 1 分。

| 模块 | 分数 |
| --- | ---: |
| 预备工作 1：了解编译器、LLVM IR 编程及汇编编程 | 5 |
| 实现词法分析器 | 3 |
| 实现语法分析器 | 3 |
| 类型检查与中间代码（SSA）生成 | 9 + 进阶语法 2 = 11 |
| 代码优化（进阶要求） | 4 |
| 目标代码生成、完成编译器构造 | 7 + 进阶语法 2 = 9 |

### 基本要求

基础 track 共 27 分（5 + 3 + 3 + 9 + 7），需要正确实现以下 SysY 特性：

- 数据类型：`int`。
- 变量声明、常量声明，以及常量和变量的初始化。
- 语句：赋值（`=`）、表达式语句、语句块、`if`、`while`、`return`。
- 表达式：算术运算（`+`、`-`、`*`、`/`、`%`，其中 `+`、`-` 也可作为单目运算符）、关系运算（`==`、`>`、`<`、`>=`、`<=`、`!=`）和逻辑运算（`&&`、`||`、`!`）。
- 函数与语句块。
- 函数声明与函数调用。
- 变量和常量的作用域：处理函数、嵌套语句块内的变量与常量声明，以及 `break`、`continue` 语句。
- 注释。
- 输入输出：连接 SysY 运行时库，参见 [SysY 2022 运行时库](SysY2022运行时库-V1.md)。

此外还需实现代码优化功能。

### 进阶要求

竞赛 track 共 8 分（2 + 4 + 2）。

#### 进阶语法要求

实现以下 SysY 特性。类型检查与中间代码生成阶段产出正确的中间代码可得 2 分，目标代码生成阶段产出正确的汇编代码可再得 2 分：

- 数组：一维、二维及更高维数组的声明和数组元素访问。
- 浮点数：浮点数常量识别，以及变量声明、存储和运算。
- 张量类型。

#### 进阶优化要求

模块 5 中需要实现：

1. 完整的 SSA 形式转换（完整的 `mem2reg`）、消除不可达基本块、删除无用语句，共 2 分。
2. 自由发挥，共 2 分：完成 `mem2reg` 后，从下列优化中任选两项，或实现难度不低于下列项目的其他优化。多完成可酌情加分。
   - 稀疏条件常量传播。
   - 标量运算的循环不变量外提。
   - 标量运算的公共子表达式删除。
   - 函数内联。
   - 激进的死代码消除：基于控制依赖图，并需要删除 dead loop。

> 进阶部分总分 8 分中，功能实现检查占 3 分，答辩占 5 分。

## 三 其他要求

- **开发平台**：Linux 系统，使用 C/C++，以 GCC 或 LLVM/Clang 编译。
- **目标语言**：生成 ARM 或 RISC-V 汇编程序，二者任选其一。采用 Linux 系统 AT&T 风格，并使用 GCC 或 LLVM/Clang 将汇编程序链接成二进制可执行程序。
- **辅助工具**：鼓励借助 Flex、Bison、ANTLR 等工具构造词法分析器和语法分析器。
- **组队要求**：两人一组完成。

### 提交内容

1. 所实现 SysY 子集的描述，包括词法结构的正则表达式定义和语法结构的上下文无关文法（Context-Free Grammar, CFG）定义。
2. 编译器源程序文本，包括 Lex、Yacc 等程序和 C/C++ 程序。
3. 编译器完成度由助教检查并结合 SysY 测试用例评分。

## 四 学术诚信

历年全国编译系统设计赛获奖作品会公开源代码，课程实验教学指导书也会依据助教的获奖作品讲解各模块的设计与实现。请遵守以下原则：

- 可以借鉴公开源码中的思想，重新设计自己的编译器框架和具体代码。
- 如果参考了公开源码，必须在代码注释中明确注明；参考较多时会酌情扣分。
- 参考公开源码但未在注释中注明的，按抄袭处理，当次作业计零分。
